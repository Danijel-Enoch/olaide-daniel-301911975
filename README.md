Transactions: COMMIT, ROLLBACK, READ COMMITTED against REPEATABLE READ, SERIALIZABLE write skew, deadlock detection and prevention, and a two-session lost-update comparison with and without row locking. Seven timestamped transcripts.

Distributed design: a five-node PostgreSQL cluster with streaming replication, a measured synchronous-commit cost, a failover with standby promotion, and hash sharding across two nodes through postgres_fdw. The cloud deployment is a written design; no cloud provider was used.

Reproduction
Use PostgreSQL 18, MongoDB 8 and Redis 7 as Docker containers in fresh databases. Follow the README in each portfolio folder. Run the Portfolio 1 schema, then its constraints, then its seed data, in that order. Portfolio 2 requires the baseline measurement before the indexes are created. Portfolio 3 requires Python 3 and opens two or three database sessions. Portfolio 4 uses mongosh and redis-cli. Portfolio 5 uses docker compose and its replication lab promotes a standby, so the cluster must be recreated before the lab is run again. Deliberately invalid statements are expected to fail; the recorded evidence shows their actual results.

Scope and limitations
All records are fictional and generated by a seeded script, so the data and every measurement are reproducible. No real customer or transaction data is present. The organisation does not exist. Timings come from one laptop running Docker, are single-client and warm, and measure plan quality rather than throughput. The concurrency results demonstrate that an anomaly can occur, not how often it occurs under load. The daily debit limit is enforced in the Redis example and in the SERIALIZABLE demonstration, but not inside the transfer function. The MongoDB validator cannot express the equality of debits and credits, so that invariant is enforced only in PostgreSQL, which remains the single system of record. Cassandra and Neo4j are presented as designs and were not deployed. The cluster has no WAL archiving and therefore no point-in-time recovery, and its failover is manual.
